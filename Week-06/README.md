# Week 6 – Apache Spark Architecture & Data Processing

## Overview

This repository contains the **Week 6 Assignment** completed as part of the **Celebal Technologies Data Engineering Summer Internship 2026**.

The objective of this assignment is to understand Apache Spark architecture and perform efficient distributed data processing using Spark DataFrames. The notebook covers Spark architecture, lazy evaluation, transformations, actions, schema handling, filtering, performance optimization, and working with different file formats such as CSV and Parquet.
