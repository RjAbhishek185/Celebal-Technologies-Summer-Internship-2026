# Raw Data

This folder contains the original datasets generated using Python.

## Files

| File | Description |
|---|---|
| `customers.csv` | Customer information |
| `products.csv` | Product information |
| `orders.csv` | Order information |
| `order_items.csv` | Individual order items |

## Intentional Data Issues

The raw data was intentionally generated with inconsistencies to simulate real-world data.

Issues include:

- Missing customer IDs
- Invalid email addresses
- Negative quantities
- Product name formatting inconsistencies
- Incorrect date formats

The raw datasets are used as input for the data-cleaning phase.
