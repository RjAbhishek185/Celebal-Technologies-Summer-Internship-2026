# Celebal Technologies Internship – Week 8 Report

## E-Commerce Order Analytics System

This folder contains the final report for **Week 8** of the Celebal Technologies Data Engineering Internship.

The report documents the complete implementation of an **E-Commerce Order Analytics System** using Python, SQL, and SQLite.

## Report

The final assignment report is available below:

**`Celebal_Week_08_ECommerce_Order_Analytics_Report.docx`**

## Contents of the Report

The report covers all major phases of the Week 8 assignment:

- Phase 1 – Data Verification
- Phase 2 – Data Cleaning
- Phase 3 – SQLite Database Creation
- Phase 4 – SQL Analytics
- Phase 5 – Command-Line Reporting
- Phase 6 – Edge Case Testing

## SQL Analysis

The report includes **16 SQL analytical queries** covering:

- Revenue analysis
- Customer analysis
- Monthly order analysis
- Return analysis
- Running totals
- Ranking
- Customer order gaps
- Customer segmentation
- Customer lifetime value
- Year-over-year revenue comparison
- First and last purchased categories
- Cumulative revenue distribution
- Cohort retention analysis
- Self-join and window-function analysis

## Reporting System

The report also documents the Python-based command-line reporting system supporting:

- Daily reports
- Weekly reports
- Monthly reports
- Previous-period comparison
- Revenue comparison
- Order comparison
- Top 3 products

## Edge Case Testing

The following edge cases were tested:

1. Invalid Order ID
2. Discount Greater Than 100%
3. Zero Quantity
4. Future Order Date

All four tests were successfully completed.
